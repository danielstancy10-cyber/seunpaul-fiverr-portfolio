# Windows setup — ELI10

This is the part you do once. After that, day-to-day portfolio updates happen inside the dashboard.

## 1. Open the project

Extract the ZIP, then open PowerShell inside the project folder.

## 2. Create `.env.local`

Copy `.env.example` to `.env.local`.

Example:

```powershell
Copy-Item .env.example .env.local
```

Then open `.env.local` and fill in:

```env
DATABASE_URL="your-postgresql-connection-string"
ADMIN_PASSWORD="a-long-strong-password"
ADMIN_SECRET="a-long-random-secret-at-least-32-characters"
NEXT_PUBLIC_SITE_URL="https://your-real-domain.com"
GOOGLE_SITE_VERIFICATION=""
```

Do not share the database URL, admin password, or admin secret.

## 3. Install the app

```powershell
npm install
```

## 4. Create the database tables

```powershell
npm run db:push
```

## 5. Add the starting 7 portfolio projects

```powershell
npm run db:seed
```

## 6. Start the website

```powershell
npm run dev
```

Open:

```text
http://localhost:3000
```

Dashboard:

```text
http://localhost:3000/dashboard
```

## 7. Daily workflow after deployment

You do NOT edit `app/page.tsx` to add portfolio work.

Use:

```text
/dashboard
→ Projects
→ + Add project
→ enter project details
→ Save changes
```

You can also hide a project, publish it again, change its order, or delete it.

## 8. Add a real video later

Open the project in the dashboard and choose:

```text
Visual type = Video / MP4 / WebM
```

Then paste the public video URL.

For an image:

```text
Visual type = Image
```

and paste the public image URL.

## 9. Deploy to Vercel

Push the project to GitHub and import the repository into Vercel.

Add these Vercel environment variables:

```text
DATABASE_URL
ADMIN_PASSWORD
ADMIN_SECRET
NEXT_PUBLIC_SITE_URL
GOOGLE_SITE_VERIFICATION
```

Run the Prisma database setup once against your production database before relying on the dashboard.

## 10. Google Search Console

Use the dashboard's Site settings screen for the Google verification token and your final domain.

Then submit:

```text
https://your-real-domain.com/sitemap.xml
```

The sitemap and robots files are generated by Next.js from the configured domain.
